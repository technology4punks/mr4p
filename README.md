# NEO — Conversational Mixed Reality Avatar (MVP)

Progetto sperimentale web-first per un avatar conversazionale in Mixed Reality su Meta Quest Pro, con esperienza alternativa su Android e iPhone.

**Stato:** specifica di sviluppo pronta per Codex; implementazione da completare.

- **[SPEC.md](./SPEC.md)**: specifiche tecniche dettagliate, requisiti e test di accettazione.
- **[AGENTS.md](./AGENTS.md)**: istruzioni eseguibili per Codex.

## Per iniziare con Codex Cloud
Seleziona questo repository GitHub con la branch `codex/neo-ar-avatar-mvp`, quindi chiedi: 

> Implementa interamente SPEC.md seguendo AGENTS.md. Non fermarti alla pianificazione. Completa frontend e backend, esegui test, segnala limiti WebXR e apri una pull request verso main.

Non salvare chiavi OpenAI nel codice. La compatibilità XR, il rilevamento del pavimento e la persistenza degli ancoraggi richiedono test effettivi sul Quest Pro.

Il precedente progetto su `main` rimane intatto finché una pull request non viene unita.
